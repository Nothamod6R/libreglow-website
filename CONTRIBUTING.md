# Contributing to LibreGlow

First of all, thank you for considering contributing to LibreGlow! ❤️

LibreGlow is an open-source organization dedicated to building modern, high-quality software that is free, transparent, and community-driven.

Every contribution, no matter how small, helps improve the project.

---

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Fixing issues
* Improving performance
* Writing tests
* Enhancing accessibility
* Improving translations
* Reviewing pull requests

---

## Before You Start

Before opening a Pull Request:

* Search existing issues to avoid duplicates.
* Discuss large features by opening an Issue first.
* Keep changes focused on a single purpose.
* Follow the project's coding style.

---

## Development Setup

Clone the repository:

```bash
git clone https://github.com/libreglow/website.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

---

## Commit Messages

Please write clear and descriptive commit messages.

Examples:

```
feat: add project showcase section

fix: resolve mobile navigation bug

docs: update README

refactor: simplify footer component
```

---

## Pull Requests

Before submitting a Pull Request, make sure that:

* Your code builds successfully.
* There are no linting errors.
* The feature has been tested.
* The Pull Request has a clear description.

---

## Code Style

Please follow these principles:

* Keep code simple.
* Prefer readability over cleverness.
* Write reusable components.
* Avoid unnecessary dependencies.
* Keep files well organized.

---

## Be Respectful

We strive to maintain a welcoming and friendly community.

Please:

* Be respectful.
* Be constructive.
* Help others learn.
* Welcome newcomers.

---

## Questions

If you have any questions, feel free to open a Discussion or Issue.

Thank you for helping make LibreGlow better! 💙
