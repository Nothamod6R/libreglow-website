# LibreGlow Website

The official website of **LibreGlow**.

This repository contains the landing page and public website for the LibreGlow organization, built with modern web technologies and focused on performance, accessibility, and clean design.

<center>
  <img src="/public/og-image.png"/>
</center>

##  Features

- Modern responsive design
- Fast page loading
- SEO optimized
- Accessible UI
- Dark mode support
- Smooth animations
- Project showcase
- Community links
- Open source

##  Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- shadcn UI

##  Project Structure

```
app/
components/
public/
```

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/libreglow/website.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
